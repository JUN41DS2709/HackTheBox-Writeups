# Hack The Box — Writeups & Walkthroughs

Welcome to my **Hack The Box (HTB) Writeups Repository**!

This repository documents my hands-on cybersecurity learning journey through Hack The Box. I use it to record the machines, challenges, and walkthroughs I complete, along with the techniques, tools, and concepts I learn along the way.

My goal is to strengthen my practical skills in **penetration testing, enumeration, vulnerability assessment, Linux and Windows security, and privilege escalation** while building a structured knowledge base for my future in cybersecurity.

## 🛠️ Skills & Topics Covered

- **Reconnaissance & Enumeration:** Nmap, service discovery, directory enumeration
- **Web Application Security:** SQL injection, authentication flaws, file inclusion, and other web vulnerabilities
- **Exploitation:** Vulnerability analysis and controlled exploitation
- **Privilege Escalation:** Linux and Windows privilege escalation
- **Networking:** Ports, protocols, services, and network troubleshooting
- **Scripting & Automation:** Python, Bash, and security tools
- **Post-Exploitation:** Understanding access, permissions, and system security
- **Documentation:** Methodology, findings, remediation, and lessons learned

## Writeup Methodology

Each machine or challenge writeup aims to follow a consistent methodology:

1. **Target Overview** — Basic information about the target.
2. **Reconnaissance** — Initial information gathering and port scanning.
3. **Enumeration** — Identifying services, technologies, and potential attack surfaces.
4. **Vulnerability Analysis** — Investigating weaknesses and possible attack vectors.
5. **Exploitation** — Documenting the steps used to gain access.
6. **Privilege Escalation** — Exploring paths to higher privileges, where applicable.
7. **Proof & Validation** — Recording relevant results and evidence.
8. **Key Learnings** — Summarizing new concepts, mistakes, and takeaways.

Not every writeup will contain all these sections; the methodology will depend on the target and challenge.
